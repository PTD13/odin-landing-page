# odin-landing-page
Simple landing page as demonstrated in the Landing Project project description on [The Odin Project](https://www.theodinproject.com/). This is the second project in the The Odin Project curriculum.

This will only consist of a single html page with the appropriate CSS styles in order to match the image given by Odin Project. 

By completing this project, I will have demonstrated my ability to:
* Create and structure web pages using HTML
* Link CSS file to HTML page
* Use selectors to apply desired CSS styles wherever I want
* Work with FlexBox
